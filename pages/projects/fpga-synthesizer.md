# FPGA Music Synthesizer

A music synthesizer implemented in Verilog on an FPGA that plays classic Zelda tracks.

## Features

- Support for harmonics and multiple voices
- Custom ROM format for storing music data
- Real-time audio synthesis on FPGA hardware

Built as part of EE108 (Digital System Design).
